# FinanciApp

Sistema simples de finanças pessoais: registre entradas e saídas, veja o saldo do mês, os gastos por categoria e a evolução dos últimos 6 meses.

## Como usar

Abra o `index.html` no navegador. Não precisa instalar nada.

Os lançamentos ficam salvos no próprio navegador (localStorage). Use o botão **Exportar CSV** para guardar uma cópia.

## Recursos

- Entradas e saídas com valor, descrição, categoria e data
- Saldo do mês e saldo acumulado
- Gastos por categoria
- Gráfico dos últimos 6 meses
- Filtro por tipo, busca, edição e exclusão
- Exportação em CSV
